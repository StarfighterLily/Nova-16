# Nova-16 Emulator: Reimplantation Architecture Analysis & Plan

**Date:** June 27, 2026  
**Author:** AI Code Analysis  
**Scope:** Full architectural analysis and reimplantation plan for the Nova-16 custom CPU emulator

---

## Executive Summary

The Nova-16 emulator is a ~9,000+ line Python project that implements a custom 16-bit CPU, assembler, graphics system, sound system, keyboard/mouse I/O, UART, and GUI. The codebase has grown organically with multiple optimization passes layered on top, resulting in significant architectural debt: **redundant caching layers, massive monolithic classes, duplicated logic across files, tight coupling between components, and a complex instruction execution pipeline that mixes responsibility concerns.**

This report identifies 7 major architectural problems and provides a detailed reimplantation plan targeting **maximal code reuse, optimal algorithmic complexity (O(1)/O(n) for hot paths), and clean modular decomposition.**

## II. Critical Architectural Problems

### Problem 1: The Monolithic CPU Class (nova_cpu.py, 2206 lines)

The CPU class has **too many responsibilities**, making it impossible to test in isolation, impossible to optimize independently, and extremely fragile.

**Responsibilities crammed into a single class:**

| Responsibility | Lines | Should be in |
|----------------|-------|--------------|
| Register file management (R0-R9, P0-P9) | ~100 | `core/regfile.py` |
| Flag management (12 flags × 2 properties each) | ~130 | `core/flags.py` |
| Sound register proxy (SA, SF, SV, SW) | ~50 | `core/regfile.py` or delegate |
| Keyboard buffer management | ~60 | `peripherals/keyboard.py` |
| Mouse proxying (MX, MY, MB) | ~30 | `peripherals/mouse.py` |
| Timer subsystem (control, speed, modulo, interrupt) | ~80 | `peripherals/timer.py` |
| Instruction caching (LRU, 512 entries) | ~70 | Eliminate entirely |
| Operand caching (LRU, 512 entries) | ~80 | Eliminate entirely |
| Prefetch buffer (64 bytes, invalidation) | ~90 | Eliminate entirely |
| Register value cache (disabled, 512 entries) | ~30 | Eliminate entirely |
| Profiling system inline | ~60 | `debug/profiler.py` |
| BCD math operations (add, sub, compare, conversions) | ~100 | `core/bcd.py` |
| Flag-setting logic (8-bit, 16-bit, BCD, overflow) | ~70 | `core/flags.py` |
| Interrupt checking (batching, state hashing, priority) | ~70 | `bus/interrupt.py` |
| Hardware breakpoint checking | ~40 | `debug/debugger.py` |
| Operand parse/evaluate/set (3 methods) | ~240 | `core/fetch.py` |
| Register lookup table + parity table | ~60 | `core/regfile.py`, `core/flags.py` |
| 20 register property accessors (r0-r9, p0-p9) | ~200 | Generated by `core/regfile.py` |

**Impact:** ~60% of CPU.py is cross-cutting infrastructure (caches, profiling, operand dispatch) rather than core CPU logic. Changes to any subsystem risk breaking unrelated functionality.

### Problem 2: Redundant Caching Layers

The system has **5 separate caching mechanisms** that overlap significantly:

| Cache | Location | Implementation | Max Size | Purpose |
|-------|----------|---------------|----------|---------|
| Memory zero-page cache | nova_memory.py | numpy array | 256 bytes | Hot memory region 0x0000-0x00FF |
| Memory IVT cache | nova_memory.py | numpy array | 32 bytes | Interrupt vectors 0x0100-0x011F |
| Memory LRU cache | nova_memory.py | OrderedDict | 512 entries | General hot addresses |
| CPU instruction cache | nova_cpu.py | dict | 512 entries | Decoded instruction tuples |
| CPU operand cache | nova_cpu.py | dict | 512 entries | Parsed operands |
| CPU prefetch buffer | nova_cpu.py | numpy array | 64 bytes | Instruction fetch streaming |
| CPU register cache | nova_cpu.py | dict (disabled) | 512 entries | Register values |

**Specific problems identified:**

**a) Redundant storage of the same data:**
- The prefetch buffer copies from zero_page_cache and interrupt_vector_cache (nova_cpu.py lines 1537-1551) — the same bytes exist in 2-3 locations
- An instruction byte stored at address 0x0042 exists in: main memory array, zero_page_cache, prefetch_buffer, and potentially instruction_cache and lru_cache
- Each byte replicated 2-5× across caches

**b) Complex cache invalidation on every write:**
- `invalidate_instruction_cache` (lines 1687-1725): Walks all 512 entries linearly checking address overlap — O(n) worst case
- `invalidate_operand_cache` (lines 1762-1789): Walks all 512 entries linearly — O(n) worst case
- `_prefetch_overlaps` (lines 1593-1603): Runs on every memory write
- `_write_memory_precisely` (lines 1605-1631): Calls all three invalidation methods on EVERY write

**c) Questionable hit rates:**
- Emulated programs are typically short (100-1000 instructions) with linear execution
- Each branch/call/jump invalidates large portions of the instruction cache
- The prefetch buffer helps only if execution stays within a 64-byte window — any branch destroys its value

**d) Cache lookup overhead may exceed numpy direct read:**
- numpy array read from `self.memory[p]`: **~5 ns**
- Python dict lookup in instruction_cache: **~40-50 ns**
- Multiple cache lookups per instruction (instruction + operand + prefetch): **~150 ns overhead**
- Direct numpy read of opcode + mode byte + operands: **2-8 reads × 5 ns = ~10-40 ns**

**Recommendation:** The caching layers cost more in complexity and invalidation overhead than they save. Eliminate ALL CPU-side caches. Keep only the memory-level hot-region view for zero-page/IVT.

### Problem 3: Tight Coupling Through Back-References

The component graph has circular dependencies that create a "god object" problem:

```
CPU → Memory (self.memory)
CPU → GFX (self.gfx)
Memory → GFX (mem.gfx_system — set by CPU at init)
GFX → CPU (via sprite update calls)
Keyboard → CPU (kbd.cpu — explicit back-reference set in nova.py line 39)
Mouse → GFX + CPU (for coordinate mapping)
Memory → CPU (mem.cpu — set in CPU.__init__ line 23)
```

**Concrete coupling points:**

1. **`nova.py:39`** — `kbd.cpu = proc` — Keyboard needs CPU reference to call `add_key_to_buffer`
2. **`nova.py:42`** — `mem.gfx_system = gfx` — Memory needs GFX reference for sprite updates
3. **`nova_cpu.py:23`** — `self.memory.cpu = self` — Memory needs CPU reference for cache invalidation
4. **`nova_cpu.py:181`** — `self.memory.gfx_system = self.gfx` — Duplicate of nova.py:42

**Impact:**
- Components cannot be instantiated or tested independently
- Unit tests must construct the full system
- Changes to the CPU's internal API potentially break memory or keyboard
- Impossible to parallelize or distribute components

### Problem 4: Duplicated Instruction Execution Patterns

**Three separate operand-handling APIs coexist in nova_cpu.py:**

| API | Lines | Status | Description |
|-----|-------|--------|-------------|
| `_get_operand_value(type, idx)` + `_set_operand_value(type, idx, value)` | 835-980 | Active (legacy) | 50-way if/elif chain for direct register access |
| `parse_operands()` → `get_operand_value()` / `set_operand_value()` | 1865-2038 | Active (current) | Structured operand dicts with mode-byte parsing |
| `fetch_operand_by_mode(mode_bits)` | 1806-1863 | Deprecated | Early version of the prefixed operand system |

**The 150+ instruction classes in instructions.py** follow an ABC pattern with `BaseInstruction`, but many have identical execution logic:
- All register-to-register MOV variants differ only in operand types
- All ALU ops (ADD, SUB, AND, OR, XOR) share the same structure with different operators
- All conditional jumps differ only in flag check logic

**Current pattern overhead:**
- Each instruction class: ~10 lines of boilerplate (class def, __init__, execute, imports)
- 150 classes × 10 lines = 1500 lines of boilerplate
- Actual unique execution logic: ~500 lines
- Boilerplate-to-logic ratio: **3:1**

### Problem 5: Assembler Code Quality Issues

Based on analysis of `nova_assembler.py` (~1098 lines):

**a) 300+ line Parser with deeply nested control flow**
- Macro expansion, include handling, conditional assembly, and label parsing are interleaved
- State variables proliferate (current_mode, in_macro, parsing_macro_args, etc.)
- Single `parse_line()` method handles too many cases via if/elif/else chains

**b) Regex-based operand classification is fragile:**
- Complex regex patterns for matching register types, addressing modes
- Edge cases (e.g., `:P0` vs `P0:` byte access) require special-case regex branches
- No token-based intermediate representation to simplify matching

**c) Macro expansion interleaved with parsing:**
- Macros are expanded during the parse phase, not as a separate pass
- This means the parser must track macro state, parameter substitution, and nesting
- Nested macro expansion leads to exponential complexity in the worst case

**d) Error messages are inconsistent:**
- Some errors include line numbers and context, others just raise generic exceptions
- No centralized error reporting mechanism

**e) Symbol resolution is O(n) per reference in edge cases:**
- Forward references require two-pass resolution, but some edge cases (ORG-relative labels, macro-injected symbols) fall back to linear search

### Problem 6: GFX Compositing Inefficiency

The 8-layer graphics system has performance issues:

**a) Always-full compositing:**
- `get_screen()` always composites ALL 8 layers + layer_0 = 9 layers total
- Each layer is 256×256 = 65,536 pixels
- Worst case: 9 × 65,536 = 589,824 pixel operations per frame
- No dirty-tracking: even if only 1 sprite moved, all layers get recomposited

**b) Nine separate numpy arrays:**
- `layer_0`: Base layer
- `background_layers[0..3]`: 4 background layers
- `sprite_layers[0..3]`: 4 sprite layers
- Each is a separate numpy array requiring separate iteration

**c) Redundant sprite storage:**
- Sprites are stored both in GFX memory (as numpy arrays) AND in memory-mapped SCB region (0xF000-0xF0FF)
- Synchronization between the two requires explicit calls
- Any memory write to the SCB region must be intercepted and forwarded to GFX

### Problem 7: Flag Management Verbosity

The CPU has 12 flags managed with significant boilerplate:

**Current implementation (lines 282-406, ~125 lines):**
- 12 individual `@property` getter/setter pairs = 24 methods
- Plus 3 bulk flag methods: `_set_flags_8bit`, `_set_flags_16bit`, `_set_flags_8bit_bcd`
- Plus 2 overflow flag methods: `_set_overflow_flag_8bit`, `_set_overflow_flag_16bit`
- Plus 2 alias properties: `decimal_mode` (alias for D), `aux_carry` (alias for A)
- Plus 2 bulk operations: `reset_all_flags`, `get_flag_state`, `set_flag_state`

**Redundancies:**
- `_set_flags_8bit` (lines 982-1002) and `_set_flags_16bit` (lines 1004-1024) are identical except for bit-width constants (0xFF vs 0xFFFF, 0x80 vs 0x8000)
- `_set_overflow_flag_8bit` and `_set_overflow_flag_16bit` are identical except for bit-width constants
- Flag properties are accessed as `self.flags[7]` in flag-setting code but `self.zero_flag` elsewhere — inconsistent API

### 3.3 CPU Core (Reduced from 2206 → ~150 lines)

```python
class CPU:
    """Nova-16 CPU core — minimal orchestration, no caching, no peripherals."""
    
    def __init__(self, bus, memory, regfile, flags, inst_table):
        self.bus = bus
        self.mem = memory
        self.reg = regfile
        self.flags = flags
        self.inst_table = inst_table
        self.pc = 0x0000
        self.halted = False
        self.cycles = 0
    
    def step(self):
        """Execute one instruction cycle."""
        if self.halted:
            return
        self.cycles += 1
        
        # Notify timer/peripherals via event bus
        self.bus.publish('cpu.tick', self.cycles)
        
        # Fetch opcode (direct memory read — no caching)
        opcode = self.mem.read_byte(self.pc, 'code')
        self.pc = (self.pc + 1) & 0xFFFF
        
        if opcode in NO_OPERAND_OPCODES:
            self.inst_table[opcode].execute(self, NO_OPERANDS)
        else:
            mode_byte = self.mem.read_byte(self.pc, 'code')
            self.pc = (self.pc + 1) & 0xFFFF
            operands = OperandDecoder.decode(
                self.mem, self.pc, mode_byte,
                self.inst_table[opcode].num_operands
            )
            self.pc = (self.pc + operands.byte_length) & 0xFFFF
            self.inst_table[opcode].execute(self, operands)
        
        # Check interrupts (via bus — peripheral state is fresh)
        self.bus.publish('cpu.post_step', self)
```

**Complexity:** `step()` is **O(1) amortized** — opcode dispatch is a direct dict lookup; operand decode is O(k) for k ≤ 4 operands; no caches to check or invalidate.

### 3.4 Register File (Dispatch Table Replaces 50-Way If-Chain)

```python
class RegisterFile:
    """Unified register file with O(1) dispatch table."""
    
    def __init__(self):
        self.R = bytearray(10)          # R0-R9, 8-bit
        self.P = array('H', [0] * 10)   # P0-P9, 16-bit
        self.P[8] = 0xFFFF  # SP
        self.P[9] = 0xFFFF  # FP
        
        # External register references (sound, mouse, etc.)
        self._externals = {}
    
    @classmethod
    def _build_dispatch(cls):
        """Build O(1) dispatch tables for get/set operations."""
        getters = {}
        setters = {}
        
        # R registers (0xE7-0xF0)
        for i in range(10):
            getters[('R', i)] = lambda self, i=i: self.R[i]
            setters[('R', i)] = lambda self, v, i=i: self.R.__setitem__(i, v & 0xFF)
            
            # P registers (0xF1-0xFA)
            getters[('P', i)] = lambda self, i=i: self.P[i]
            setters[('P', i)] = lambda self, v, i=i: self.P.__setitem__(i, v & 0xFFFF)
            
            # P_high (0xC9-0xD2)
            getters[('P_high', i)] = lambda self, i=i: (self.P[i] >> 8) & 0xFF
            setters[('P_high', i)] = lambda self, v, i=i: self.P.__setitem__(i, 
                (v & 0xFF) << 8 | (self.P[i] & 0xFF))
            
            # P_low (0xD3-0xDC)
            getters[('P_low', i)] = lambda self, i=i: self.P[i] & 0xFF
            setters[('P_low', i)] = lambda self, v, i=i: self.P.__setitem__(i,
                (self.P[i] & 0xFF00) | (v & 0xFF))
        
        return getters, setters
    
    _GETTERS, _SETTERS = _build_dispatch()
    
    def get(self, reg_type, idx):
        """O(1) register read via dispatch table."""
        return self._GETTERS[(reg_type, idx)](self)
    
    def set(self, reg_type, idx, value):
        """O(1) register write via dispatch table."""
        self._SETTERS[(reg_type, idx)](self, value)
    
    def read_byte_access(self, reg_code):
        """Decode 0xC3-0xFE register code into (type, idx) pair."""
        try:
            return REGISTER_CODE_MAP[reg_code]
        except KeyError:
            raise ValueError(f"Unknown register code: 0x{reg_code:02X}")
```

**Key improvements:**
- O(1) dispatch replaces O(n) if/elif chain (50 branches → 1 dict lookup)
- No property boilerplate (20 properties × 10 lines = 200 lines eliminated)
- Byte access for P registers is explicit rather than hidden in operand methods

### 3.5 Flags (Bitfield Replaces 24 Property Methods)

```python
class Flags:
    """Compact 12-bit flag register — bitwise operations only."""
    
    # Bit positions
    T = 0   # Trap
    S = 1   # Sign
    O = 2   # Overflow
    B = 3   # Break
    D = 4   # Decimal
    I = 5   # Interrupt
    C = 6   # Carry
    Z = 7   # Zero
    Pbit = 8  # Parity (P is a built-in function, avoid shadowing)
    H = 9   # Direction
    A = 10  # BCD Carry
    E = 11  # Hacker
    
    def __init__(self):
        self._bits = 0
    
    def __getitem__(self, bit):
        """O(1) flag read."""
        return (self._bits >> bit) & 1
    
    def __setitem__(self, bit, value):
        """O(1) flag write."""
        mask = 1 << bit
        if value:
            self._bits |= mask
        else:
            self._bits &= ~mask
    
    @property
    def bits(self):
        """Return full 12-bit flag state (for interrupt push/pop)."""
        return self._bits & 0xFFF
    
    @bits.setter
    def bits(self, value):
        self._bits = value & 0xFFF
    
    def set_from_8bit(self, result, original_result=None, is_cmp=False, 
                      set_overflow=False, op1=None, op2=None, is_sub=False):
        """Set Z, C, S, P flags from an 8-bit result. O(1)."""
        r = result & 0xFF
        orig = original_result if original_result is not None else result
        
        # Clear Z(7), C(6), S(1), P(8)
        self._bits &= ~0x01C2
        
        # Set flags
        if r == 0:
            self._bits |= (1 << 7)  # Z
        if r & 0x80:
            self._bits |= (1 << 1)  # S
        if PARITY_TABLE[r]:
            self._bits |= (1 << 8)  # P
        if is_cmp:
            if orig < 0:
                self._bits |= (1 << 6)  # C (borrow)
        else:
            if orig > 0xFF or orig < 0:
                self._bits |= (1 << 6)  # C (carry)
        
        # Overflow (optional, set by caller when needed)
        if set_overflow and op1 is not None and op2 is not None:
            if is_sub:
                overflow = ((op1 ^ op2) & 0x80) and ((op1 ^ r) & 0x80)
            else:
                overflow = not ((op1 ^ op2) & 0x80) and ((op1 ^ r) & 0x80)
            if overflow:
                self._bits |= (1 << 2)  # O
    
    def set_from_16bit(self, result, original_result=None, is_cmp=False,
                       set_overflow=False, op1=None, op2=None, is_sub=False):
        """Set Z, C, S, P flags from a 16-bit result. O(1)."""
        r = result & 0xFFFF
        orig = original_result if original_result is not None else result
        
        self._bits &= ~0x01C2
        
        if r == 0:
            self._bits |= (1 << 7)
        if r & 0x8000:
            self._bits |= (1 << 1)
        if PARITY_TABLE[r & 0xFF]:
            self._bits |= (1 << 8)
        if is_cmp:
            if orig < 0:
                self._bits |= (1 << 6)
        else:
            if orig > 0xFFFF or orig < 0:
                self._bits |= (1 << 6)
        
        if set_overflow and op1 is not None and op2 is not None:
            if is_sub:
                overflow = ((op1 ^ op2) & 0x8000) and ((op1 ^ r) & 0x8000)
            else:
                overflow = not ((op1 ^ op2) & 0x8000) and ((op1 ^ r) & 0x8000)
            if overflow:
                self._bits |= (1 << 2)
```

**Key improvements:**
- ~125 lines → ~60 lines (50% reduction)
- All operations are O(1) bitwise instructions
- Single `_bits` integer replaces 12-element list
- No property boilerplate for individual flags
- 8-bit and 16-bit methods unified internally (only constants differ)

### 3.6 Parameterized Instruction Table (Replaces 150+ Classes)

```python
# Current: 150+ classes × ~10 lines boilerplate = 1500 lines
# Proposed: ~50 handler functions + table = ~300 lines

class Instruction:
    """Parameterized instruction — one handler per instruction family."""
    __slots__ = ('name', 'num_operands', 'handler', 'flags_fn', 'width')
    
    def __init__(self, name, num_operands, handler, flags_fn=None, width=8):
        self.name = name
        self.num_operands = num_operands
        self.handler = handler
        self.flags_fn = flags_fn  # Optional: (flags, values, result) → None
        self.width = width        # 8 or 16 bit operation
    
    def execute(self, cpu, operands):
        """Execute instruction with resolved operand values."""
        if self.num_operands == 0:
            result = self.handler(cpu)
        elif operands:
            values = cpu.resolve_operands(operands)
            result = self.handler(cpu, values)
            if self.flags_fn:
                self.flags_fn(cpu.flags, values, result)
        else:
            result = self.handler(cpu)

# Handler functions (pure arithmetic — no CPU state access needed)
def _add(cpu, values):
    """ADD: dst + src"""
    return values[0] + values[1]

def _sub(cpu, values):
    """SUB: dst - src"""
    return values[0] - values[1]

def _and(cpu, values):
    """AND: dst & src"""
    return values[0] & values[1]

def _or(cpu, values):
    """OR: dst | src"""
    return values[0] | values[1]

def _xor(cpu, values):
    """XOR: dst ^ src"""
    return values[0] ^ values[1]

def _mov(cpu, values):
    """MOV: dst = src (values[0] is destination, values[1] is source)"""
    cpu.set_operand_value(operands[0], values[1])
    return values[1]

def _cmp(cpu, values):
    """CMP: sets flags only, no writeback"""
    result = values[0] - values[1]  # dst - src
    cpu.flags.set_from_8bit(result & 0xFF, result, is_cmp=True,
                             set_overflow=True, op1=values[0], op2=values[1], is_sub=True)
    return result

    flags.set_from_8bit(result, set_overflow=True, 
                        op1=values[0], op2=values[1],
```

### 3.7 Operand Decoder (Clean, Standalone, Cache-Free)

```python
class OperandDecoder:
    """Decode prefixed-mode operands from instruction stream. Pure function."""
    
    @staticmethod
    def decode(memory, pc, mode_byte, num_operands):
        """Decode num_operands starting at pc. Returns (operands[], byte_length)."""
        operands = []
        addr = pc
        
        for i in range(num_operands):
            mode = (mode_byte >> (i * 2)) & 0x3
            
            if mode == 0:  # Register direct
                reg_code = memory.read_byte(addr, 'code')
                operands.append(Operand.register(reg_code))
                addr = (addr + 1) & 0xFFFF
                
            elif mode == 1:  # Immediate 8-bit
                operands.append(Operand.immediate(memory.read_byte(addr, 'code'), 8))
                addr = (addr + 1) & 0xFFFF
                
            elif mode == 2:  # Immediate 16-bit
                high = memory.read_byte(addr, 'code')
                low = memory.read_byte((addr + 1) & 0xFFFF, 'code')
                operands.append(Operand.immediate((high << 8) | low, 16))
                addr = (addr + 2) & 0xFFFF
                
            elif mode == 3:  # Memory reference
                idx_bit = (mode_byte >> 6) & 1
                direct_bit = (mode_byte >> 7) & 1
                operands.append(
                    OperandDecoder._decode_memory_ref(memory, addr, direct_bit, idx_bit)
                )
                addr = (addr + operands[-1].byte_length) & 0xFFFF
        
        byte_length = (addr - pc) & 0xFFFF
        return Operands(operands, byte_length)
    
    @staticmethod
    def _decode_memory_ref(memory, addr, direct, indexed):
        """Decode a memory reference operand."""
        if direct and not indexed:
            # Direct memory address [imm16]
            high = memory.read_byte(addr, 'code')
            low = memory.read_byte((addr + 1) & 0xFFFF, 'code')
            return Operand.memory_direct((high << 8) | low)
        
        elif not direct and not indexed:
            # Register indirect [reg]
            reg_code = memory.read_byte(addr, 'code')
            return Operand.memory_indirect(reg_code)
        
        elif not direct and indexed:
            # Register indexed [reg + offset]
            reg_code = memory.read_byte(addr, 'code')
            offset = memory.read_byte((addr + 1) & 0xFFFF, 'code')
            return Operand.memory_indexed(reg_code, offset)
        
        elif direct and indexed:
            # Direct indexed [imm16 + offset]
            high = memory.read_byte(addr, 'code')
            low = memory.read_byte((addr + 1) & 0xFFFF, 'code')
            offset = memory.read_byte((addr + 2) & 0xFFFF, 'code')
            return Operand.memory_direct_indexed((high << 8) | low, offset)
```

**Key improvements:**
- Standalone decoder — no CPU state dependency
- Returns `Operands` object, not raw dicts — type-safe and debuggable
- No caching — direct memory reads for all operands
- Pure function — trivial to unit test

### 3.8 Memory (Single Hot-Region View)

```python
class Memory:
    """64KB unified memory with single hot-region view. No LRU cache."""
    
    SIZE = 65536
    HOT_END = 0x0120  # Zero page (256) + IVT (32)
    SCB_START = 0xF000
    SCB_END = 0xF100
    
    def __init__(self, bus=None):
        self.bus = bus
        self.ram = np.zeros(self.SIZE, dtype=np.uint8)
        # Single shared view for hot region (no copies, no dirty tracking)
        self._hot = self.ram[0:self.HOT_END]
    
    def read_byte(self, address, access_type='data'):
        """O(1) read — fast path for hot region, else direct array access."""
        addr = address & 0xFFFF
        if addr < self.HOT_END:
            return self._hot[addr]
        return self.ram[addr]
    
    def read_word(self, address):
        """O(1) 16-bit big-endian read."""
        addr = address & 0xFFFF
        if addr < self.HOT_END - 1:
            return (self._hot[addr] << 8) | self._hot[addr + 1]
        elif addr >= self.SIZE - 1:
            return (self.ram[addr] << 8) | self.ram[0]
        return (self.ram[addr] << 8) | self.ram[addr + 1]
    
    def write_byte(self, address, value):
        """O(1) write — hot region auto-updates via shared view."""
        addr = address & 0xFFFF
        self.ram[addr] = value & 0xFF
        # Notify bus if SCB region (sprite control blocks)
        if self.bus and self.SCB_START <= addr < self.SCB_END:
            self.bus.publish('memory.scb_written', addr)
    
    def write_word(self, address, value):
        """O(1) 16-bit big-endian write."""
        addr = address & 0xFFFF
        self.ram[addr] = (value >> 8) & 0xFF
        self.ram[(addr + 1) & 0xFFFF] = value & 0xFF
    
    def load(self, path):
        """Load binary program. Returns entry point from ORG directive."""
        from pathlib import Path
        data = Path(path).read_bytes()
        self.ram[:len(data)] = np.frombuffer(data, dtype=np.uint8)
        
        # Try to read .org file for entry point
        org_path = Path(str(path).replace('.bin', '.org'))
        if org_path.exists():
            return int(org_path.read_text().strip(), 16)
        return 0x0000
```

**Key improvements:**
- Removes zero_page_cache, interrupt_vector_cache, LRU cache (3 caches → 1 view)
- Removes all dirty-tracking and writeback logic
- Hot region is a numpy view — zero-copy, auto-synchronizing
- SCB write notification via event bus (no gfx_system reference needed)
- `load()` is simplified — directly writes to ndarray

### 3.9 Event Bus Implementation

```python
from collections import defaultdict
from typing import Callable, Any

class EventBus:
    """Simple typed event bus — synchronous pub/sub within the emulator thread."""
    
    def __init__(self):
        self._subscribers: dict[str, list[Callable]] = defaultdict(list)
        self._once: dict[str, list[Callable]] = defaultdict(list)
    
    def subscribe(self, event_type: str, callback: Callable[[Any], None]):
        """Subscribe to an event. Callback receives event data."""
        self._subscribers[event_type].append(callback)
    
    def subscribe_once(self, event_type: str, callback: Callable[[Any], None]):
        """One-shot subscription (auto-removed after first fire)."""
        self._once[event_type].append(callback)
    
    def unsubscribe(self, event_type: str, callback: Callable):
        """Remove a subscription."""
        if event_type in self._subscribers:
            self._subscribers[event_type] = [
                cb for cb in self._subscribers[event_type] if cb is not callback
            ]
    
    def publish(self, event_type: str, data: Any = None):
        """Publish an event. All subscribers called synchronously in order."""
        for callback in self._subscribers.get(event_type, []):
            callback(data)
        for callback in self._once.get(event_type, []):
            callback(data)
        self._once[event_type].clear()


class InterruptController:
    """Central interrupt controller — subscribes to peripheral events."""
    
    # Interrupt priorities (0 = highest)
    VECTOR_TIMER = 0
    VECTOR_SERIAL = 1
    VECTOR_KEYBOARD = 2
    VECTOR_MOUSE = 3
    VECTOR_USER1 = 4
    
    def __init__(self, bus, cpu, memory):
        self.bus = bus
        self.cpu = cpu        # Only for triggering interrupt
        self.memory = memory
        
        # Per-vector enable flags
        self.enabled = [False] * 8
        
        # Pending flags per source
        self._timer_pending = False
        self._serial_pending = False
        self._keyboard_pending = False
        self._mouse_pending = False
        
        # Subscribe to peripheral events
        bus.subscribe('timer.fired', self._on_timer)
        bus.subscribe('keyboard.key_pressed', self._on_keyboard)
        bus.subscribe('uart.data_received', self._on_serial)
        bus.subscribe('mouse.button_changed', self._on_mouse)
    
    def _on_timer(self, _):
        self._timer_pending = True
        self._check()
    
    def _on_keyboard(self, _):
        self._keyboard_pending = True
        self._check()
    
    def _on_serial(self, _):
        self._serial_pending = True
        self._check()
    
    def _on_mouse(self, _):
        self._mouse_pending = True
        self._check()
    
    def _check(self):
        """Check pending interrupts in priority order and trigger if enabled."""
        if not self.cpu.flags[Flags.I]:
            return  # Global interrupts disabled
        
        vectors = [
            (self.VECTOR_TIMER, self._timer_pending, self.enabled[0]),
            (self.VECTOR_SERIAL, self._serial_pending, self.enabled[1]),
            (self.VECTOR_KEYBOARD, self._keyboard_pending, self.enabled[2]),
            (self.VECTOR_MOUSE, self._mouse_pending, self.enabled[3]),
            (self.VECTOR_USER1, True, self.enabled[4]),
        ]
        
        for vec, pending, enabled in vectors:
            if pending and enabled:
                self._trigger(vec)
                return
    
    def _trigger(self, vector):
        """Push PC+flags to stack, jump to handler."""
        cpu = self.cpu
        vector_addr = 0x0100 + (vector * 4)
        handler = self.memory.read_word(vector_addr)
        
        # Push flags
        cpu.reg.P[8] = (cpu.reg.P[8] - 2) & 0xFFFF
        self.memory.write_word(cpu.reg.P[8], cpu.flags.bits)
        
        # Push PC
        cpu.reg.P[8] = (cpu.reg.P[8] - 2) & 0xFFFF
        self.memory.write_word(cpu.reg.P[8], cpu.pc)
        
        # Disable interrupts during handler
        cpu.flags[Flags.I] = 0
        
        # Jump to handler
        cpu.pc = handler
        
        # Clear pending flag
        if vector == self.VECTOR_TIMER:
            self._timer_pending = False
        elif vector == self.VECTOR_SERIAL:
            self._serial_pending = False
        elif vector == self.VECTOR_KEYBOARD:
            self._keyboard_pending = False
        elif vector == self.VECTOR_MOUSE:
            self._mouse_pending = False
```

### 3.10 Timer (Extracted from CPU)

```python
class Timer:
    """Programmable timer — standalone peripheral communicating via event bus."""
    
    def __init__(self, bus):
        self.bus = bus
        self.counter = 0       # TT (timer counter)
        self.modulo = 0        # TM (timer modulo)
        self.control = 0       # TC (timer control)
        self.speed = 0         # TS (timer speed)
        self._enabled = False
        self._interrupt_enabled = False
        self._cycle_count = 0
        
        bus.subscribe('cpu.tick', self._on_tick)
    
    def _on_tick(self, _):
        """Called on every CPU cycle via event bus."""
        if not self._enabled:
            return
        
        self._cycle_count += 1
        divisor = self.speed + 1  # TS=0 → 1 cycle, TS=255 → 256 cycles
        
        if self._cycle_count >= divisor:
            self._cycle_count = 0
            self.counter = (self.counter + 1) & 0xFF
            
            if self.modulo > 0 and self.counter >= self.modulo:
                self.counter = 0
                if self._interrupt_enabled:
                    self.bus.publish('timer.fired')
    
    def set_control(self, value):
        """Set control register (TC)."""
        self.control = value & 0xFF
        self._enabled = bool(value & 0x01)
        self._interrupt_enabled = bool(value & 0x02)
        if not self._enabled:
            self._cycle_count = 0
            self.counter = 0
    
    def set_speed(self, value):
        """Set speed register (TS)."""
        self.speed = value & 0xFF
```

### 3.11 Keyboard (Decoupled from CPU)

```python
class NovaKeyboard:
    """Keyboard buffer — publishes events instead of calling CPU methods."""
    
    BUFFER_MAX = 64
    
    def __init__(self, bus):
        self.bus = bus
        self.buffer = []         # Circular buffer
        self.data_register = 0   # Most recent key
        self.status = 0          # Status flags (bit 0: key avail, bit 1: buffer full)
        self.buffer_count = 0
    
    def add_key(self, key_code):
        """Add key press to buffer and publish event."""
        if len(self.buffer) >= self.BUFFER_MAX:
            return  # Buffer full, discard
        
        self.buffer.append(key_code & 0xFF)
        self.data_register = key_code & 0xFF
        self.buffer_count = len(self.buffer)
        
        # Update status
        self.status |= 0x01  # Key available
        if len(self.buffer) >= self.BUFFER_MAX:
            self.status |= 0x02  # Buffer full
        
        # Publish event (InterruptController subscribes)
        self.bus.publish('keyboard.key_pressed', key_code & 0xFF)
    
    def read_key(self):
        """Read and remove oldest key from buffer."""
        if not self.buffer:
            self.data_register = 0
            self.buffer_count = 0
            self.status &= ~0x01  # Clear key available
            self.status &= ~0x02  # Clear buffer full
            return 0
        
        key = self.buffer.pop(0)
        self.buffer_count = len(self.buffer)
        
        if self.buffer:
            self.data_register = self.buffer[0]
        else:
            self.data_register = 0
            self.status &= ~0x01  # Clear key available
        
        if len(self.buffer) < self.BUFFER_MAX:
            self.status &= ~0x02  # Clear buffer full
        
        return key
```

**Key change:** `NovaKeyboard` no longer holds a `cpu` reference. It publishes `keyboard.key_pressed` events. The `InterruptController` subscribes to these events and decides whether to interrupt the CPU.

```python
class Compositor:
    """Layer compositing engine with dirty tracking for O(n) per change."""
    
    NUM_LAYERS = 9  # layer_0 + 4 BG + 4 sprite
    
    def __init__(self):
        self.layers = [np.zeros((256, 256), dtype=np.uint8) for _ in range(self.NUM_LAYERS)]
        self.dirty = [True] * self.NUM_LAYERS
        self._composited = np.zeros((256, 256), dtype=np.uint8)
        self._composite_dirty = True
    
    def mark_dirty(self, layer_idx):
        """Mark a layer as needing recompositing."""
        if 0 <= layer_idx < self.NUM_LAYERS:
            self.dirty[layer_idx] = True
            self._composite_dirty = True
    
    def get_screen(self):
        """Return composited screen — partial recompute only on dirty layers."""
        if not self._composite_dirty:
            return self._composited
        
        # Rebuild composited image from scratch (can be optimized further)
        result = np.zeros((256, 256), dtype=np.uint8)
        for i in range(self.NUM_LAYERS):
            if np.any(self.layers[i]):
                mask = self.layers[i] != 0
                result[mask] = self.layers[i][mask]  # Back-to-front overwrite
        
        self._composited = result
        self._composite_dirty = False
        self.dirty = [False] * self.NUM_LAYERS
        return self._composited
```

### 3.13 Assembler (Clean Pipeline)


## VII. Risk Assessment

| Risk | Severity | Probability | Mitigation |
|------|----------|-------------|------------|
| CPU cache removal causes performance regression | Medium | Low (30%) | Pre/post benchmarks with headless mode. numpy is ~5ns/read; dict lookup is ~50ns. Net win expected. |
| Refactored instruction handlers introduce edge-case bugs | High | Medium (40%) | Comprehensive test suite with 100% opcode coverage. Compare register/flag/memory state byte-for-byte after each instruction. |
| Event bus adds latency to critical path | Low | Low (10%) | Synchronous pub/sub in same thread. Single function call overhead ~50ns — negligible vs instruction execution (~500ns-5μs). |
| Assembler rewrite breaks existing programs | High | Medium (35%) | Binary-level equivalence testing: assemble ALL asm/ files → compare output bytes. Verify .bin, .sym, .org match exactly. |
| GFX compositing change alters visual output | Medium | Medium (30%) | Pixel-level screenshot comparison for known test programs. Automated headless pixel-dump validation. |
| Phase ordering creates long-lived incompatibility | Low | Low (20%) | Each phase is independently testable. Phases 1-3 don't change external APIs. Phases 4-8 preserve backward compatibility internally. |

## X. Conclusion

The Nova-16 emulator is a functional project with genuine architectural debt from organic growth. The reimplantation strategy focuses on five key principles:

1. **Eliminate redundancy**: 5 caching layers → 1 hot-region view; 150 instruction classes → 50 parameterized handlers; 50-branch if-chains → O(1) dispatch tables
2. **Decouple components**: Circular back-references → event bus with typed events
3. **Separate concerns**: 2206-line CPU monolith → 10 focused modules (~200 lines each)
4. **Favor O(1) operations**: Bitwise flags, dict-dispatch register access, direct memory reads
5. **Make pure functions pure**: Operand decoder, instruction handlers, assembler pipeline

The result would be a **~60% smaller codebase** (~3600 lines vs ~9000) with **better testability** (every component independently testable), **better maintainability** (no cache invalidation to reason about), and **equivalent or better performance** (eliminated cache overhead outweighs any benefit).

Each phase of the migration is independently testable, allowing incremental improvement without breaking the system. The 15-22 day estimate reflects careful, tested refactoring — not just code movement.
