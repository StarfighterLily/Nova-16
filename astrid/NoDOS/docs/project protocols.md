'src' is for source directories/files
'build' is for the final executable
'docs\plans' is for any documentation pertinent to the implementation of the project
'docs\notes' is for detailed developer notes for other developers to read and add to.

Use header comments for the 'what's and inline comments for the 'why's.
Keep detailed notes in the 'docs\notes' directory pertinent to the section being worked on so each
document is a living testament to the work done and problems faced. If a document becomes too long,
make a note at the end of the previous document pointing to the continuation document.
