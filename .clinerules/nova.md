# Nova-16 AI Agent Coding Guidelines

## Core Principles
- **Never assume implementation details**—always check code and patterns in the repo before making changes.
- **Work incrementally**: Make small, testable changes and validate frequently.
- **Double-check all edits**: Even minor mistakes can cause major issues in this emulator.
- **Use project-specific workflows and patterns**—see below for concrete examples.

## Key Project Patterns
- **Register/flag access**: Use explicit register names (R0–R9, P0–P9) and follow byte-access conventions (`P0:`, `:P0` for high/low bytes).
- **Memory layout**: Respect zero page (0x0000-0x00FF), interrupt vectors (0x0100-0x011F), and sprite control block (0xF000-0xF0FF).
- **Component integration**: All subsystems communicate via EventBus; no circular back-references.
- **Testing**: Use pytest markers (`unit`, `integration`, `cpu`, `assembler`, `graphics`, `memory`, `sound`) and validate register/flag state after execution.
- **Assembly workflow**: Always assemble `.asm` to `.bin` before running or debugging. Use `.sym` files for symbol lookup (optional).
- **Error handling**: Print PC and error details on exceptions.

## Core Architecture

NOVA-16 is a custom 16-bit CPU emulator with Princeton architecture (unified memory) featuring 64KB shared memory. The architecture uses a **Phase-based reimplantation strategy** to modularize components:

### Phase 1-2: Core Extraction
- **RegisterFile** ([`core/regfile.py`](core/regfile.py)): Unified O(1) register dispatch for R0-R9 (8-bit) and P0-P9 (16-bit)
- **Flags** ([`core/flags.py`](core/flags.py)): Compact 12-bit bitfield (T, S, O, B, D, I, C, Z, P, H, A, E)

### Phase 3-4: Event Bus Architecture
- **EventBus** ([`nova/bus/eventbus.py`](nova/bus/eventbus.py)): Synchronous pub/sub for component communication
- **InterruptController** ([`nova/bus/interrupt.py`](nova/bus/interrupt.py)): Central interrupt management
- **Timer** ([`nova/peripherals/timer.py`](nova/peripherals/timer.py)): Standalone peripheral subscribing to `cpu.tick` events

### Phase 5-6: Performance & Refactoring
- **Memory** ([`nova/memory/memory.py`](nova/memory/memory.py)): Single hot-region view, instruction cache, no LRU cache
- **Graphics** ([`nova/graphics/`](nova/graphics/)): Modular (Compositor, SpriteEngine, Blitter)
- **Exec** ([`core/exec.py`](core/exec.py)): Parameterized Instruction dataclass with pure handler functions

**Key Components:**
- [`nova_cpu.py`](nova_cpu.py) - CPU core with regfile, flags_obj, interrupt_controller, timer_device
- [`nova/memory/memory.py`](nova/memory/memory.py) - 64KB unified memory with numpy arrays, instruction cache
- [`nova/graphics/gfx.py`](nova/graphics/gfx.py) - 8-layer graphics (256×256) with sprite control
- [`nova_sound.py`](nova_sound.py) - Programmable sound with waveforms (8 channels)
- [`nova_keyboard.py`](nova_keyboard.py) - Circular key buffer, publishes `keyboard.key_pressed` events
- [`nova_uart.py`](nova_uart.py) - Serial communication with TCP/terminal bridge support
- [`nova_assembler.py`](nova_assembler.py) - Modern 2-pass assembler with macros and conditionals
- [`nova_mcp_server.py`](nova_mcp_server.py) - MCP server with ~30+ tools

## Critical Patterns

### Register Usage
- **R0-R9**: 8-bit general purpose registers (stored in `RegisterFile.R` list)
- **P0-P9**: 16-bit general purpose registers (stored in `RegisterFile.P` list)
- **SP**: Stack pointer (P8) — starts at 0xFFFF
- **FP**: Frame pointer (P9) — starts at 0xFFFF
- **Special Graphics**: VX (0xFD), VY (0xFE), VM (0xE1), VC (0xC8), VL (0xE2) via Vregisters array
- **Sound**: SA (0xDD), SF (0xDE), SV (0xDF), SW (0xE0)
- **Timer**: TT (0xE3), TM (0xE4), TC (0xE5), TS (0xE6)
- **RTC**: C0 (0xC3), C1 (0xC4) — read-only real-time clock
- **Mouse**: MX (0xC5), MY (0xC6), MB (0xC7)
- **Byte Access**: `P0:` high byte, `:P0` low byte (opcode 0xC9-0xD2 and 0xD3-0xDC)

### Memory Layout
- **0x0000-0x00FF**: Zero page (fast access via hot view)
- **0x0100-0x011F**: Interrupt vectors (8 vectors × 4 bytes each)
- **0x0120-0xEFFF**: General memory (64KB total)
- **0xF000-0xF0FF**: Sprite control blocks (16 sprites × 16 bytes)
- **SCB Event**: Writes to 0xF000-0xF0FF publish `memory.scb_written` on bus

### Hardware Access Patterns
```asm
; Graphics system (coordinates via VX/VY, or address mode via VM=1)
MOV VM, 0           ; Coordinate mode (VM=0, VX/VY = x,y)
MOV VL, 0           ; Active layer (0-8)
MOV VX, 100         ; X coordinate
MOV VY, 120         ; Y coordinate
SWRITE 0x1F         ; Write pixel/color to screen at (VX, VY)

; Sound system
MOV SA, 0x2000      ; Sound Address (points to sample data)
MOV SF, 128         ; Sound Frequency (0-255 maps to ~55-1760Hz)
MOV SV, 128         ; Sound Volume (0-255)
MOV SW, 0x87        ; Sound Waveform: bits 0-2=7 (memory sample), bits 3-5=0 (channel 0), bit 7=1 (enable)
SPLAY               ; Start sound playback

; Keyboard input
KEYIN R0            ; Read key into R0 (0 if none available)
KEYSTAT R0          ; Check status: bit 0 = key ready, bit 1 = buffer full

; Timer
MOV TT, 0           ; Timer counter
MOV TM, 100         ; Modulo threshold
MOV TC, 0x03        ; Control: bit 0=enable, bit 1=interrupt enable
MOV TS, 0           ; Speed divisor (TS+1 cycles per tick)
```

### Conditional Jumps and Comparisons
```asm
; Comparison sets flags for conditional jumps
CMP R0, R1          ; Compare R0 with R1, sets Z/C/S/O flags

; Signed comparisons (use overflow and sign flags)
JLT label           ; Jump if less than (signed): (O ⊕ S) = 1
JGE label           ; Jump if greater or equal (signed)
JGT label           ; Jump if greater than (signed)
JLE label           ; Jump if less or equal (signed)

; Unsigned comparisons (use carry flag)
JC label            ; Jump if carry (unsigned: val1 < val2)
JNC label           ; Jump if no carry (unsigned: val1 >= val2)

; Other conditions
JZ label            ; Jump if zero (equal)
JNZ label           ; Jump if not zero (not equal)
JS label            ; Jump if sign (negative, bit 7 set)
JNS label           ; Jump if no sign (positive/zero)
JO label            ; Jump if overflow
JNO label           ; Jump if no overflow
```

### Flag Setting in Comparisons
- **CMP op1, op2** performs `result = op1 - op2` and sets flags
- **T(0)**: Trap flag (single-step mode)
- **S(1)**: Sign flag (result bit 7/15 set)
- **O(2)**: Overflow flag (signed overflow)
- **B(3)**: Break flag (breakpoint hit)
- **D(4)**: Decimal flag (BCD mode)
- **I(5)**: Interrupt flag (global interrupt enable)
- **C(6)**: Carry flag (borrow for CMP, overflow for other ops)
- **Z(7)**: Zero flag (result is zero)
- **P(8)**: Parity flag (even number of 1 bits in low byte)
- **H(9)**: Direction flag (CPU runs High to Low)
- **A(10)**: BCD Carry flag (BCD operation carry/borrow)
- **E(11)**: Hacker flag (user-defined, not modified by CPU)

## Component Integration

### Event Bus Pattern
```python
# Components communicate via event bus, not circular references
from nova.bus import EventBus
bus = EventBus()

# Peripherals subscribe to events
bus.subscribe('cpu.tick', timer._on_tick)
bus.subscribe('keyboard.key_pressed', intr_ctrl._on_keyboard)

# Peripherals publish events
bus.publish('timer.fired')
bus.publish('memory.scb_written', address)
```

### System Initialization (from nova_main.py)
```python
def initialize_system(enable_sound=True, uart_config=None):
    bus = EventBus()
    mem = ram.Memory(bus=bus)
    gfx = gpu.GFX()
    kbd = keyboard.NovaKeyboard(bus=bus)
    snd = sound.NovaSound() if enable_sound else None
    uart_device = uart.NovaUART(host_bridge=uart.create_host_bridge(uart_config))
    
    intr_ctrl = InterruptController(bus=bus, memory=mem)
    timer_dev = Timer(bus=bus, interrupt_controller=intr_ctrl)
    
    proc = cpu.CPU(mem, gfx, kbd, snd, uart_device=uart_device,
                   bus=bus, interrupt_controller=intr_ctrl, timer_device=timer_dev)
    
    intr_ctrl.cpu = proc
    bus.subscribe('cpu.post_step', intr_ctrl.check)
    
    return proc, mem, gfx, kbd, snd
```

## Project Conventions

### File Organization
- `asm/` - Assembly examples and tests
- `NoBASIC/` - High-level BASIC-type language compiler (optional)
- `astrid/` - High-level C-type language compiler (optional)
- `tests/` - Test suite organized by component
- `docs/` - Documentation
- `nova/` - Core modules (memory, graphics, peripherals, bus)
- `core/` - Extracted subsystems (regfile, flags, exec, fetch)
- `nova_mcp/` - MCP integration modules

### Code Generation Pipeline
1. **Assembly** (`.asm`) → **Binary** (`.bin` + `.org` + `.sym`)
2. **NoBASIC** (`.nb`) → **Assembly** (`.asm`) → **Binary** (`.bin` + `.org` + `.sym`)
3. **NoBASIC** (`.ast`) → **Assembly** (`.asm`) → **Binary** (`.bin` + `.org` + `.sym`)
4. **Binary Loading**: Uses `.org` file for segment-aware loading if present

### Assembler Features
- 2-pass assembly (labels resolved in pass 2)
- Comprehensive operand types: immediate, register, indirect, indexed, direct
- Symbol table export (`.sym`) for debugging
- ORG directive sets program segment address
- P register byte access: `P0:` (high byte), `:P0` (low byte)
- Macro support with parameters and recursion
- Conditional assembly: `IF`, `IFDEF`, `IFNDEF`, `ELSE`, `ENDIF`
- Include directives: `INCLUDE "filename"`

### Error Handling
```python
try:
    proc.step()
except Exception as e:
    print(f"Error at PC: 0x{proc.pc:04X}: {e}")
```

### Register State Inspection Pattern
When testing or debugging, always capture final state:
```python
# Access via properties (R0-R9, P0-P9, SP, FP)
print(f"R0: 0x{proc.r0:02X}")
print(f"P0: 0x{proc.p0:04X}")

# Or access the underlying lists for bulk operations
print(f"R0-R9: {[f'0x{r:02X}' for r in proc.Rregisters[:10]]}")
print(f"P0-P9: {[f'0x{r:04X}' for r in proc.Pregisters[:10]]}")

# Flags access (list-style or property)
print(f"Z={proc.flags[7]}, C={proc.flags[6]}, I={proc.flags[5]}")
print(f"Zero: {proc.zero_flag}, Carry: {proc.carry_flag}")
```
